Тестовое задание для AQA стажёра в компании учи

Подготовка к работе
-------------------

Для начала работы убедитесь, что у вас установлены [node.js + npm](https://nodejs.org/en/download)

Установите зависимости проекта, выполнив команду:
```shell
npm ci
```

Запуск тестов
-------------

Запустите тесты с помощью команды:
```shell
npx playwright test
```

Примечания
----------

Тесты запускаются в установленном Google Chrome в headed-режиме (`channel: 'chrome'`
в `playwright.config.ts`): анти-бот uchi.ru блокирует headless-браузеры и встроенный
Chromium Playwright, из-за чего виджет поддержки не загружается на странице.
